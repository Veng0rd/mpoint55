# MPoint55 — вариант 2

Статическая версия редизайна для GitHub Pages. Точка входа — `index.html`, клиентская логика — `app.js`.

## Публикация

1. Загрузите содержимое каталога в GitHub-репозиторий.
2. В **Settings → Pages** выберите **Deploy from a branch**.
3. Укажите ветку `main` и каталог `/ (root)`.

Данные товаров хранятся в `live-data.json`. Workflow `Update catalog data` раз в час запускает `update-data.mjs`, читает актуальные карточки на mpoint55.ru и фиксирует изменения в репозитории. Его также можно запустить вручную на вкладке **Actions**.

GitHub Pages не поддерживает серверный код и mpoint55.ru не разрешает браузерные CORS-запросы. Поэтому обновление выполняется через GitHub Actions; встроенный снимок страниц остаётся резервным источником, если сайт временно недоступен.

Локальный просмотр:

```powershell
npx serve .
```
